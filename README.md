# penny-pr-screenshots

Durable public hosting for screenshots referenced from [getpenny/penny](https://github.com/getpenny/penny) pull request descriptions.

Images are organized as `pr-<number>/<filename>.png` and intended for GitHub-rendered inline markdown:

```markdown
![descriptive alt](https://raw.githubusercontent.com/adrw-bot/penny-pr-screenshots/main/pr-320/after_history.png)
```

Not a product release. Maintained by automation for PR description durability (Cursor agent artifact links are auth-walled HTML, not raw images).
